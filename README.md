# VatusToolbox

Данный набор скриптов родился в результате моей различной администраторской деятельности. 
Он не особо связан одной темой, но отражает определенные задачи которые мне приходилось автоматизировать и я подумал что это может пригодится еще кому то. 
Скрипты снабжены комментариями на русском языке и могут помочь начинающим администраторам проще погрузится в их механику. 

**Темы скриптов:**

- maincraft_server - Задачи автоматизации личного ванильного сервера java maincraft.
- Linux - Задачи автоматизации администрирования GNU Linux
